# 📈 Extracting and Visualizing Stock Data

Financial data analysis project focused on extracting, cleaning, and visualizing stock market and revenue data using Python, APIs, and Web Scraping techniques.

---

## 🌎 Languages

- 🇺🇸 [English](README.en.md)
- 🇧🇷 [Português](README.pt-BR.md)

---

## Highlights

- Historical stock data extraction with **Yahoo Finance (yfinance)**
- Revenue data collection through **Web Scraping (BeautifulSoup)**
- Analysis of **Tesla (TSLA)** and **GameStop (GME)**
- Data cleaning and transformation using **Pandas**
- Financial data visualization with **Matplotlib**
- Comparison between stock market performance and company revenue
- Practical application of API consumption and HTML parsing techniques

---

## Technologies

- Python
- Pandas
- yFinance
- Requests
- BeautifulSoup4
- Matplotlib
- Jupyter Notebook

---

## Project Scope

This project analyzes:

- Tesla historical stock prices and quarterly revenue
- GameStop historical stock prices and quarterly revenue
- Relationships between business performance and market valuation
- Financial datasets obtained from multiple data sources
